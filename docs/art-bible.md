# Direction artistique (port Unity)

Tirée de la référence HTML du ch1 (Perralière). À valider par Mich.

- **Style** : album jeunesse en 2D vue de dessus, formes rondes, contour encre foncé, interface en cartes de papier posées sur le jeu.
- **Palette** : encre `#2b3a55`, nuit `#1f2433`, papier `#fffaf0`, rouge `#e5483a`, jaune `#ffd25a`, vert `#5fc06a`, bleu `#4f9fd8`, rose `#ff9ec0`, violet `#c97ad8`, bois `#8a5f3c`.
- **Lumière** : plein jour constant (pas de cycle jour/nuit), lumière 2D globale blanche, pas d'ombres dures.
